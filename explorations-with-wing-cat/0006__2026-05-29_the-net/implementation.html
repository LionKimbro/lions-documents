Implementation

A small first version

The first build should be intentionally small. It should prove the capture-to-stage-to-tag-to-archive loop before adding search, sync, OCR, previews, browser automation, or formal taxonomy tools.

The success criterion is not elegance in the abstract. It is whether Lion can save things while browsing and later find them by rough tags.

Minimum components

scan_bookmarks.py

Reads Chrome bookmark drop files, writes normalized records into staging, and refreshes the rolling recent page context.

scan_downloads.py

Finds new downloaded files, copies assets into the archive area, and stages records with suggested parent context when timing supports it.

state/recent_context.json

Stores the most recent page-like capture for a short window so downloads can inherit a suggested framing page.

tagger_window.py

Displays staged records, manages the tag brush, accepts or rejects source suggestions, opens items, and archives selected records.

remembered-stuff.jsonl

Stores one complete remembered thing per line, suitable for append-only capture and later indexing.

First milestone

Make the loop real

Milestone one should avoid fancy intelligence. Watch a known folder. Convert bookmark drops. Keep recent context. Suggest parent pages for nearby downloads. Apply tags. Append JSONL. Move processed staging files aside.

Once that loop is pleasant, it becomes meaningful to add richer previews, duplicate detection, OCR, source-page snapshots, tag suggestions, and curation views.

Version path

v0.1 Intake

Folder scan, bookmark scan, staging records, recent-context suggestions, manual tag brush, JSONL archive.

v0.2 Preview

Image thumbnails, URL opening, PDF/file launching, and basic record editing.

v0.3 Chrome Extension

Capture page, capture image, capture both, and preserve page URL, image URL, alt text, selected text, and current tags.

Guiding rule

Useful before comprehensive

The system should be allowed to begin as a practical little machine. A durable intake loop will teach the later archive what it wants to be.
