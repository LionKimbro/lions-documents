Interaction model

The Tag Brush

The tag brush is the center of the user experience. Instead of editing each record one by one, Lion sets a current set of tags and paints them onto selected captures.

The interface should feel closer to sorting a tray than filling out a database form.

Controls

Fast enough to use while browsing

Set the brush

Type tags, pick recent tags, or tap common tag presets such as read-later, beautiful, project, or quote.

Select captures

Use checkboxes, keyboard selection, or select-all for a batch that shares a current association.

Apply tags

The brush tags merge into the selected records without replacing existing tags.

Accept or reject source links

Suggested parents and capture groups become explicit only after Lion approves them.

Archive selected

Finished records append to JSONL and leave staging, while skipped records remain available.

Principle

Do not interrupt the noticing

The tagger should ask for only what the user can give cheaply in the moment. A title, URL, file path, timestamp, and rough tags are enough.

Descriptions, quotes, project links, and formal categories can wait for a later curation pass.
