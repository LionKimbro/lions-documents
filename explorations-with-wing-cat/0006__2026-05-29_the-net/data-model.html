Data model

The universal remembered thing

Every capture source should produce the same basic record. This gives the tagger one object shape to understand, even when the source is a bookmark, file, screenshot, tweet URL, or pasted text.

JSONL is the recommended archive format because it is append-friendly, repairable, and easy to process with small scripts.

Example record

{
  "GUID": "7f7c1a2e-9b45-4ad5-86f2-0a3edab4057c",
  "CREATED": 1780000000,
  "HUMAN_TIME": "2026-05-29 13:42:10 PDT",
  "SOURCE": "chrome-bookmark",
  "KIND": "url",
  "TITLE": "Interesting Article About Spatial Hypertext",
  "URL": "https://example.com/article",
  "FILE": null,
  "SOURCE_URL": null,
  "FRAMING_URL": "https://example.com/article",
  "PARENT_GUID": null,
  "SUGGESTED_PARENT_GUID": null,
  "SUGGESTED_PARENT_REASON": null,
  "CAPTURE_GROUP": "2026-05-29T13-42-10",
  "TAGS": ["read-later", "engelbart-vibe"],
  "MNEMONIC_TAGS": ["cool", "maybe-use"],
  "BONA_FIDE_TAGS": ["HCI", "VISUAL-LANGUAGE"],
  "DESCRIPTION": "",
  "STATUS": "staged"
}

Fields

FieldPurposeNotes
GUIDStable identityUsed for staging filenames and asset filenames.
CREATEDMachine timestampUnix time or another sortable machine format.
HUMAN_TIMEReadable capture timeUseful for browsing and repair without tooling.
SOURCEInput channelExamples: downloads-folder, chrome-bookmark, pasted, screenshot.
KINDArtifact typeExamples: url, image, pdf, text, html, unknown.
URLOrigin linkNull when the captured thing is only local.
SOURCE_URLDirect artifact URLFor images, this may be the raw image URL when known.
FRAMING_URLPage contextThe page where the artifact was seen; often more valuable than the raw file URL.
FILELocal asset pathRelative archive path, usually under assets.
PARENT_GUIDAccepted parent recordChild points to parent; children can be computed later by scanning records.
SUGGESTED_PARENT_GUIDPossible parentUsed for non-destructive, user-approved associations.
CAPTURE_GROUPShared encounter IDGroups a page, images, PDFs, and notes from the same browsing moment.
TAGSSimple combined tagsOptional convenience field for tools that do not care about tag class.
MNEMONIC_TAGSCapture-time associationsFast, rough, local memory handles.
BONA_FIDE_TAGSCurated categoriesCleaner tags applied later.

Record types

URL

Title, URL, capture time, optional source domain, and rough tags.

Image

Asset path, inferred filename title, source folder, source URL, framing URL, and suggested parent if timing implies one.

PDF

Asset path, file title, optional URL if known, later metadata extraction.
